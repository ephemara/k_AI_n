- Effect-annotated fns must declare `-> Type` + explicit `return` (else exit 127).
- Parenthesize ALL bitwise/shift mixes (`&`/`!=` parse-errors; `+`/`<<` silently
  miscompiles in assignment context — suspect parens first on codec mismatches).
- One concern per loop (fused token+mask loop silently dropped mask writes).
- `decay` and `half` are reserved (`forget_f`, `half_n`); `and`/`or` don't short-circuit;
  bulk arenas need +32 SIMD padding; one `decay` per arena per function.
- Bisect native crashes via standalone `kain/spike/` probes (own `main`, delete after).
