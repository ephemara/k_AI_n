## 3. How The Training Loop Maps (frozen 2026-10-03)

```
text/code → tokenizer_16k → bin_pack_batch → train.kain_bin → dma_read
  → fwd_forward_seq (embed → layers → LM-head → logits)
  → distil_loss_batch → bwd_* twins (seed → head → resid → ssm+dcarry
    → swiglu → norm → proj/gate, reversed over positions AND layers)
  → adam_step (shadows, embed, gamma, A/B/C, skip) → re-quantize → repeat
```

Loop is **closed on CPU**: forward ingredients assembled (A2), gradients proven
per-kernel + end-to-end (A3), optimizer descends 604× on 50 tokens (A4).
`forward`/`backward`/`train` call peer kernels with zero-copy arena handoffs;
thresholds stay caller params (`CFG_RMS_EPS`/`CFG_SSM_DT` doctrine).

## 5. Bled-For Knowledge Banked By This Date

- Effect-annotated fns must declare `-> Type` + explicit `return` (else exit 127).
  Refinement: single-expression stores survive, LOOP-BODIED effect fns
  (`copy_floats`, `zero_floats`) segfault — and hid green inside `_common.kn`
  because no battery ever called them until A3.
- Parenthesize ALL bitwise/shift mixes (`&`/`!=` parse-errors; `+`/`<<` silently
  miscompiles in assignment context — suspect parens first on codec mismatches).
- One concern per loop (fused token+mask loop silently dropped mask writes).
- BPTT needs a per-position activation cache — backward through last-position
  scratch silently computes wrong gradients (caught in A4 self-review).
- Partial-gradient descent is hope, not a receipt — use the exact full chain.
- STE honesty: float shadow grads are an estimator, verified by formula, never
  claimed as FD-proven through discrete weights.
- `decay` and `half` are reserved (`forget_f`, `half_n`); `and`/`or` don't short-circuit;
  bulk arenas need +32 SIMD padding; one `decay` per arena per function.
- Bisect native crashes via standalone `kain/spike/` probes (own `main`, delete after).
